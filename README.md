# Interactive Art — MediaPipe 웹캠 아트웍 + 녹화 다운로드

웹캠 영상에 실시간 트래킹 효과를 입히고, **효과가 합성된 화면 그대로** 영상(webm)이나
사진(png)으로 저장하는 단일 페이지 앱입니다. 빌드 도구·서버·계정 모두 불필요합니다.

## 실행

카메라 권한은 `localhost` 또는 `https`에서만 허용되므로 `file://`로 직접 열면 동작하지 않습니다.

```bash
npx serve .          # 또는  python -m http.server 8777
```

브라우저에서 표시된 주소를 열고 **카메라 켜기** 버튼을 누릅니다. 같은 버튼으로 다시 끌 수 있습니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 캔버스 + 컨트롤 UI |
| `app.js` | 카메라, 모델 지연 로딩, 렌더 루프, 녹화/다운로드 |
| `roaches.js` | 바퀴벌레 잡기 게임 (스폰·도주 AI·파열 파티클) |
| `fingers.js` | 손가락 메시지 / 손가락 멜로디 |
| `style.css` | 다크 UI |

## 기술 스택

- **@mediapipe/tasks-vision 1.0.1** (CDN, ESM) — `HandLandmarker` / `FaceLandmarker`
- 브라우저 표준 API만 사용 — `getUserMedia`, Canvas 2D, `canvas.captureStream()`, `MediaRecorder`
- 프레임워크·번들러 없음

모델은 선택한 효과를 처음 켤 때만 내려받습니다(핸드 7.8MB / 페이스 3.8MB).
얼굴 모델은 손가락 메시지의 입술 판정에만 쓰입니다.

## 효과

| 효과 | 사용 모델 | 구현 |
|---|---|---|
| 바퀴벌레 잡기 | 핸드 트래킹 | 검지 끝으로 바퀴벌레를 눌러 터뜨리는 게임 |
| 손가락 메시지 | 핸드 + 페이스 | 여덟 손가락에 글자를 띄우고, 입술에 대면 글자를 읽어준다 |
| 손가락 멜로디 | 핸드 트래킹 | 여덟 손가락에 음을 배정하고, 엄지에 맞대면 실로폰이 울린다 |

### 바퀴벌레 잡기

화면에 바퀴벌레 10마리가 기어다닙니다. **검지 끝(랜드마크 8)** 이 바퀴벌레에 닿으면 터지며
점수가 오릅니다. 양손을 쓰면 검지 두 개로 잡을 수 있습니다. 검지가 몸 크기의 3배 안으로
다가가면 반대 방향으로 속도를 높여 도망가므로, 그냥 손을 휘두르는 것보다 빠르게 눌러야 잡힙니다.

- 바퀴벌레는 외부 이미지 없이 캔버스에 절차적으로 그립니다. 다리 6개는 좌우 반대 위상으로,
  더듬이는 그보다 느리게 흔들립니다.
- 터질 때 껍질 파편·즙·내장 30조각이 사방으로 날아가고, 강한 감속으로 곧 멈춰 얼룩이 된 뒤
  약 2.6초에 걸쳐 사라집니다.
- 점수와 효과음(WebAudio 노이즈 버스트)이 함께 나오며, 점수 표시는 녹화 영상에도 찍힙니다.
- 다른 효과로 갔다 돌아오면 점수가 초기화됩니다.

### 손가락 메시지

엄지를 제외한 여덟 손가락(양손 검지·중지·약지·새끼)에 글자가 하나씩 붙습니다.
기본 메시지 `I LOVE YOU`는 공백을 빼면 정확히 8글자라 손가락 수와 맞아떨어집니다.

- 손가락 끝을 **입술에 가져가면** 그 손가락의 글자를 음성으로 읽어줍니다.
  한글이면 `ko-KR`, 그 외에는 `en-US`로 발음합니다. 입술 위치는 분홍 점선 원으로
  표시됩니다. 음성 합성을 못 쓰는 브라우저에서는 음으로 대신 울립니다.
- 대고 있는 동안 반복해서 읽지 않고, 뗐다가 다시 대야 다시 발음됩니다.
- 글자 순서는 손목과 **손등 관절** 위치로 정합니다. 손끝을 기준으로 하면
  손가락을 입술로 가져가는 순간 순서가 바뀌어 다른 글자가 발음됩니다.
- 메시지는 우측 입력란에서 바꿀 수 있습니다. 8글자보다 짧으면 반복되고,
  길면 앞 8글자만 씁니다.
- 얼굴과 손을 함께 인식하므로 이 효과만 모델 두 개를 동시에 씁니다.

### 손가락 멜로디

같은 여덟 손가락에 **도-레-미-파-솔-라-시-도**를 배정하고, 손끝을 **엄지에 맞대면**
실로폰 소리가 납니다. 음은 화면 왼쪽부터 순서대로 올라가므로, 왼손 새끼가 낮은 도,
오른손 검지가 높은 도입니다.

소리는 사인파 세 개(기본음과 3.01배·6.35배 배음)를 겹쳐 만듭니다. 위 배음일수록
빠르게 감쇠시켜 나무 막대를 때리는 느낌을 냅니다.

멜로디는 손바닥을, 메시지는 손등을 카메라로 향하게 되는데 순서는 양쪽 모두 맞습니다.
손가락의 해부학적 이름이 아니라 화면에 보이는 손등 관절의 좌우 위치로 자리를 정하기
때문에, 손을 뒤집어도 화면 왼쪽부터 순서대로 읽히고 들립니다.

## 저장

- **녹화**: `canvas.captureStream(30)` → `MediaRecorder` → 정지 시 `.webm` 자동 다운로드.
  체크박스를 켜면 마이크 오디오 트랙이 함께 녹음됩니다.
- **스냅샷**: `canvas.toBlob()` → `.png` 다운로드.
- 파일명은 `artwork-<효과>-<날짜시각>.<확장자>` 형식입니다.
- 화면 좌상단의 빨간 녹화 표시는 DOM 오버레이이므로 저장된 영상에는 찍히지 않습니다.

포맷은 webm(VP9)입니다. mp4가 필요하면 별도 변환이 필요하지만, 대부분의 SNS는 webm 업로드를
지원합니다.

## 구현 메모

- `detectForVideo`의 타임스탬프는 반드시 단조 증가해야 하므로 이전 값보다 크도록 보정합니다.
- 셀피 미러링은 캔버스 트랜스폼(`setTransform(-1,0,0,1,W,0)`)으로 처리하고, 글자를 그릴 때만
  뒤집히지 않도록 트랜스폼을 일시 해제합니다.
- `video.currentTime`을 갱신하지 않는 브라우저가 있어, 그 값만으로 추론 시점을 정하면 첫
  프레임 이후 인식이 멈춥니다. 벽시계로 40ms마다 한 번은 무조건 다시 추론합니다.
- GPU 델리게이트가 생성은 되지만 결과를 내지 않는 환경이 있어, 우측 패널에서 CPU로
  전환할 수 있게 해두었습니다.
