# Interactive Artwork — MediaPipe 웹캠 아트웍 + 녹화 다운로드

웹캠 영상에 실시간 트래킹 효과를 입히고, **효과가 합성된 화면 그대로** 영상(webm)이나
사진(png)으로 저장하는 단일 페이지 앱입니다. 빌드 도구·서버·계정 모두 불필요합니다.

## 실행

카메라 권한은 `localhost` 또는 `https`에서만 허용되므로 `file://`로 직접 열면 동작하지 않습니다.

```bash
npx serve .          # 또는  python -m http.server 8777
```

브라우저에서 표시된 주소를 열고 **카메라 시작** 버튼을 누릅니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 캔버스 + 컨트롤 UI |
| `app.js` | 카메라, 모델 지연 로딩, 렌더 루프, 녹화/다운로드 |
| `effects.js` | 트래킹 효과 렌더링 + 세그멘테이션 마스크 변환 |
| `roaches.js` | 바퀴벌레 잡기 게임 (스폰·도주 AI·파열 파티클) |
| `style.css` | 다크 UI |

## 기술 스택

- **@mediapipe/tasks-vision 1.0.1** (CDN, ESM) — `HandLandmarker` / `FaceLandmarker` / `ImageSegmenter`
- 브라우저 표준 API만 사용 — `getUserMedia`, Canvas 2D, `canvas.captureStream()`, `MediaRecorder`
- 프레임워크·번들러 없음

모델은 선택한 효과를 처음 켤 때만 내려받습니다(핸드 7.8MB / 페이스 3.8MB / 바디 250KB).

## 효과

| 버튼 | 대응 | 구현 |
|---|---|---|
| Ch.4 핸드 복제 | 핸드 트래킹 | 손 랜드마크의 바운딩 박스를 비디오에서 잘라 방사형으로 14개 복제 |
| Ch.5 페이스 컷아웃 | 페이스 트래킹 | `FACE_LANDMARKS_FACE_OVAL`로 클리핑 패스를 만들고, 배경은 반복 텍스트 |
| Ch.6 바디 글로우 | 바디 트래킹 | 셀피 세그멘테이션 실루엣에 그림자를 누적한 뒤 내부를 도려내 외곽 광채만 남김 |
| Ch.7 바퀴벌레 잡기 | 핸드 트래킹 응용 | 손가락 끝으로 바퀴벌레를 눌러 터뜨리는 게임 |
| Ch.8 손가락 메시지 | 핸드 트래킹 응용 | 여덟 손가락에 글자를 띄우고, 엄지와 맞대면 소리가 난다 |

배경 텍스트는 우측 입력란에서 바꿀 수 있습니다.

### Ch.7 바퀴벌레 잡기

화면에 바퀴벌레 10마리가 기어다닙니다. **검지 끝(랜드마크 8)** 이 바퀴벌레에 닿으면 터지며
점수가 오릅니다. 양손을 쓰면 검지 두 개로 잡을 수 있습니다. 검지가 몸 크기의 3배 안으로
다가가면 반대 방향으로 속도를 높여 도망가므로, 그냥 손을 휘두르는 것보다 빠르게 눌러야 잡힙니다.

- 바퀴벌레는 외부 이미지 없이 캔버스에 절차적으로 그립니다. 다리 6개는 좌우 반대 위상으로,
  더듬이는 그보다 느리게 흔들립니다.
- 터질 때 껍질 파편·즙·내장 30조각이 사방으로 날아가고, 강한 감속으로 곧 멈춰 얼룩이 된 뒤
  약 2.6초에 걸쳐 사라집니다.
- 점수와 효과음(WebAudio 노이즈 버스트)이 함께 나오며, 점수 표시는 녹화 영상에도 찍힙니다.
- 다른 효과로 갔다 돌아오면 점수가 초기화됩니다.

### Ch.8 손가락 메시지

엄지를 제외한 여덟 손가락(양손 검지·중지·약지·새끼)에 글자가 하나씩 붙습니다.
기본 메시지 `I LOVE YOU`는 공백을 빼면 정확히 8글자라 손가락 수와 맞아떨어집니다.

- 글자는 손가락의 **화면 위치 순**으로 배정되어 왼쪽부터 순서대로 읽힙니다.
- 손가락 끝을 **엄지에 맞대면** 그 손가락에 배정된 음이 울립니다. C 메이저
  펜타토닉 8음을 왼쪽부터 낮은 음에서 높은 음으로 배치했습니다.
- 맞대고 있는 동안 반복해서 울리지 않고, 뗐다가 다시 맞대야 다시 소리가 납니다.
- 메시지는 우측 입력란에서 바꿀 수 있습니다. 8글자보다 짧으면 반복되고,
  길면 앞 8글자만 씁니다.

## 저장

- **녹화**: `canvas.captureStream(30)` → `MediaRecorder` → 정지 시 `.webm` 자동 다운로드.
  체크박스를 켜면 마이크 오디오 트랙이 함께 녹음됩니다.
- **스냅샷**: `canvas.toBlob()` → `.png` 다운로드.
- 파일명은 `artwork-<효과>-<날짜시각>.<확장자>` 형식입니다.
- 화면 좌상단의 빨간 녹화 표시는 DOM 오버레이이므로 저장된 영상에는 찍히지 않습니다.

포맷은 webm(VP9)입니다. mp4가 필요하면 별도 변환이 필요하지만, 대부분의 SNS는 webm 업로드를
지원합니다.

## 구현 메모

- `detectForVideo`의 타임스탬프는 반드시 단조 증가해야 하므로 이전 값보다 크도록 보정합니다.
- 셀피 미러링은 캔버스 트랜스폼(`setTransform(-1,0,0,1,W,0)`)으로 처리하고, 배경 텍스트만
  글자가 뒤집히지 않도록 트랜스폼을 일시 해제합니다.
- 세그멘테이션 마스크에서 어느 라벨이 배경인지는 모델마다 다르므로, 프레임 위/아래 가장자리
  픽셀의 최빈값을 배경으로 판정합니다.
